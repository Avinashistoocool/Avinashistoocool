**[Gated-Dual-Stream-Particle-Transformer](https://github.com/Avinashistoocool/Gated-Dual-Stream-Particle-Transformer)**: pairwise particle physics as multiplicative gates on Q/K plus an additive attention bias. Ragged on-disk cache, GPU pairwise features, EMA, AMP, 2.07M params. JetClass-10M test: **84.8% acc, 0.985 AUC** (ParT 10M: 85.0%, 0.986).

**[ISRO-BAH-26](https://github.com/Avinashistoocool/ISRO-BAH-26)**: Chandrayaan-2 DFSAR CPR/DOP fused with slope and roughness into a lunar ice probability map. Streams LOLA DEM tiles over GDAL `/vsicurl`, builds a slope cost map, runs octile A* to the Faustini crater floor.

**[Agnostos-v2](https://github.com/Avinashistoocool/Agnostos-v2)**: research outreach CLI. Resume parsing, OpenAlex discovery, email verification, LLM drafts with a humanizing pass, paced sends inside each recipient's local hours, reply tracking.

**[asclepius](https://github.com/Avinashistoocool/asclepius)**: search-and-rescue drone swarm. Polygon to search lanes, min-makespan fleet balancing, Hungarian dispatch of delivery drones, YOLO-World person detection.

**[eraksha-hackathon](https://github.com/Avinashistoocool/eraksha-hackathon)**: home-network anomaly detector. scapy sniffing, ARP + nmap scans, port-risk scoring, SQLite flow store, Flask dashboard, Google ADK agent.

**[Jet-Class-Particle-Visualizer](https://github.com/Avinashistoocool/Jet-Class-Particle-Visualizer)**: JetClass ROOT files to (η, φ) clouds, class heatmaps, spectra and radial profiles.

**[Object-tracking-with-color](https://github.com/Avinashistoocool/Object-tracking-with-color)**: HSV colour tracking with trajectory plots and annotated video output.
